# Oxford 3000 — كلماتي

صفحة لحفظ كلمات Oxford 3000 (من A1 إلى B2)، ومعها كلمات العمل والتقنية وiOS والبنوك.

- الموقع: https://88r8.github.io/oxford3000/
- التقدم ينحفظ على الجهاز، ويتزامن بين الأجهزة عن طريق Gist خاص (من الإعدادات ← المزامنة).
- عشان تعدّل الصفحة: عدّل `src/template.html`، وبعدها نفّذ `cd src && python3 build.py ../index.html`.

مصدر قائمة الكلمات والمستويات: [The Oxford 3000](https://www.oxfordlearnersdictionaries.com/wordlists/oxford3000-5000) من Oxford University Press. المعاني والجمل والنطق العربي كتبتها لهذي الصفحة.
